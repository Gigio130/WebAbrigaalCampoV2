Este es un proyecto para el estudio de tecnologo ADSO del  sena, aprendiendo conceptos basicos de HTML, CSS y JS, el manejo de git y github, conexion con BD, sql.
la pagina web de la fundacion abriga al campo debe cumplir con unos requisitos funcionales y no funcionales  que permitan el llenado de dormularios de acuerdo con el rol, beneficiario, colaborador o donante
un administrador funcional podra ver las incripciones, descargar datos, realizar actualizaciones y generar informes entre otros.
la idea final es que los admin de la fundacion, los usuarios, reciban correos de notificacion con la informacion de acorde al rol.
por ultimo tener una plataforma de pagos para donaciones en linea.
